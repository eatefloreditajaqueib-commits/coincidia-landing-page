# CoincidIA

## Sistema Web Inteligente para la Gestión de Objetos Perdidos y Encontrados

CoincidIA es un sistema web orientado al registro, gestión y búsqueda de objetos perdidos y encontrados, incorporando Inteligencia Artificial para apoyar la identificación de posibles coincidencias.

## Funcionalidades principales

- Registro de usuarios.
- Inicio de sesión.
- Registro de objetos perdidos y encontrados.
- Búsqueda y consulta de objetos.
- Gestión de categorías.
- Identificación de coincidencias.
- Notificaciones.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
